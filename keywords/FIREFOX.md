# Firefox

## 説明
Firefoxは、Mozillaが開発する無料で使えるウェブブラウザです。WindowsやMac、スマホなどさまざまな機器で利用でき、オープンソースとして世界中の技術者が改良に参加しています。デザインを自由に変えられるテーマや便利な拡張機能アドオン（既存のソフトウェアやアプリケーションに機能を追加するためのプログラム）が多く、標準でスクリーンショット撮影やトラッキング（特定の対象の動きや行動を追跡し、記録・分析する行為）をする広告追跡の防止機能も備えています。動作が速くプライバシーにも配慮されており、ユーザーの自由と安全を大切にしたブラウザとして根強い人気を保っています。
